# Initial release

- Eight reference-inspired ATV/SXS builds with independent cartoon body, wheel and suspension rendering.
- Cypress Bog, Backwater Ponds and Sunbreak Dunes.
- Adjustable power, springs, damping, lift, wheel size and mud/paddle/trail tires.
- Multi-touch driving, manual pitch balance, assisted wheelies, recovery and pause.
- Terrain/material painting, undo, panning and 20 device-local saved map slots.
- Veloi home shortcut and full-window player with the existing library back control.
